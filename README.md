# Algorithm Quest

An educational JavaFX game that teaches sorting and searching algorithms through interactive gameplay.

## 🎮 Game Modes

### BFS Game Levels
Navigate through a university building (UIU) to find the IT room by exploring all classrooms in the correct order. Features:
- Multiple floors 
- Interactive classrooms with numbered doors
- Washrooms with different types
- Lifts/stairs that unlock after exploring all classrooms
- 10-minute timer

### BFS Multiplayer
Compete against another player to find the IT room first!
- Real-time position tracking
- First to find the IT room wins
- Network-based gameplay

### Searching Algorithms (Library Game)
Play as a librarian searching for a required book:
- Search through bookshelves
- Find the correct book before time runs out
- 3-minute timer

### Sorting Algorithms (Cafe Game)
Work as a waiter sorting plates:
- Bubble sort mechanics
- Sort plates in correct order (Black, Red, Green, Blue, White)
- 3-minute timer

## 🛠️ Technologies Used

- Java 17+
- JavaFX 21.0.8
- Socket Programming (for multiplayer)
- FXML for UI design

## 📋 Prerequisites

- Java JDK 17 or higher
- JavaFX SDK 21.0.8
- VS Code (recommended) or any Java IDE
